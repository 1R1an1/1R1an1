# 1R1an1

Programo por hobby en **Arch Linux**. Actualmente creando herramientas de **TUI** *(TermFlow.Net)* y **GUI** *(Avalonia UI)* en **C# .NET 10**. Tambien con bases en **Kotlin (Android)**.

## Proyectos destacados

- **[Media Player](https://github.com/1R1an1/MediaPlayer)** – Reproductor de video basado en MPV solo para **Linux** `[Activo]`
- **[SharpUtils](https://github.com/1R1an1/SharpUtils)** – Librería de utilidades compartidas entre mis proyectos, para **Linux y Windows 10/11** `[Activo]`
- **[TermFlow.Net](https://github.com/1R1an1/TermFlow.Net)** – Libreria de TUI en consola para **Linux** y **Windows 10/11** `[Activo]`
- **[Dotfiles Manager](https://github.com/1R1an1/DotfilesManager)** – Herramienta para gestionar dotfiles en **Arch Linux** `[Activo]`
- **[Games Launcher](https://github.com/1R1an1/Games_Launcher)** – Launcher de juegos en WPF, con biblioteca y descargas `[Archivado]`
- **[RSM](https://github.com/1R1an1/RSM)** – Herramienta para gestionar partidas del juego *Rain World* `[Archivado]`
